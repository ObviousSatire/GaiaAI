# GAIA

**A self-learning platform for computational disease research.**

Website: [obvioussatire.github.io/GaiaAI](https://obvioussatire.github.io/GaiaAI)

## Self-learning, two layers

Reads the genome. Reads the web. Discovers its own features. Grows into a knowledge graph that improves as science advances.

## Capabilities

- Genome scanning
- Variant mapping
- Knowledge graph
- Compound libraries
- Interaction scoring
- Protocol design
- Link prediction
- Open datasets

## Build

Pure C++17 and Python stdlib. No external dependencies.
